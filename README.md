# 🤖 Titanbotics Python

Welcome to the **Titanbotics** Python code repository!

This is where we keep our team's Python programs for our FLL robot using **Pybricks**.

## 🧑‍💻 How We Work

We use **Pybricks Code** to write and test our programs.

Our basic workflow is:

1. ✏️ Write code in Pybricks Code
2. 🤖 Test it on the robot
3. 🔧 Fix any problems
4. ✅ Make sure it works
5. 📋 Copy the working code into this repository
6. 💾 Save it in the correct folder

## 📁 Where Does My Code Go?
